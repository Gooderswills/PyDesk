What is it

PyDesk is an IT helpdesk simulator written in python, run in your terminal

How to play

Download via itch.io:

  • Visit the itch.io game site
  • Download the PyDesk.exe file
  • Open the PyDesk.exe file by double clicking.
  • Play through the game in your terminal and have fun!

Download via github releases:

  • Go to the github
  • Download the PyDesk.exe file in the latest release
  • Double click to open the PyDesk.exe file
  • Play through the game in your terminal and have fun!
